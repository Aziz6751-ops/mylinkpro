# MylinkPro

MylinkPro is a modern SaaS platform designed for professionals and businesses to sell premium services, subscriptions, and packs globally.

## Features
- Premium landing page
- Pricing and plans
- User registration/login
- Dashboard and analytics
- Stripe-ready payment flow
- Admin-ready structure
- Responsive design
- Deployment-ready for Vercel

## Quick start

```bash
npm install
npm run dev
```

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS
- Stripe
- Supabase
- Vercel

## Market
- Professionals
- SMEs
- Global market
- EU and worldwide
